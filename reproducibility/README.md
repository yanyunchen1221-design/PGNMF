# PGNMF manuscript reproducibility

This directory contains a compact set of scripts for preparing evaluation
inputs and reproducing selected manuscript analyses. The installable PGNMF
implementation is maintained only in the repository-level `src/pgnmf/`
package.

## Contents

```text
reproducibility/
├── README.md
├── requirements-experiments.txt
├── configs/
│   └── c11_stage2c8_rank80.json
├── legacy/
│   └── pgnmf_revision/       # Small compatibility helpers used by selected analyses
└── scripts/
    ├── prepare_masked_input.py
    ├── evaluate_imputed.py
    ├── run_single_dataset_exact_block.py
    ├── run_truek_secondary_benchmark.py
    ├── run_convergence_analysis.py

    ├── run_additional_c11_ablation.py
    ├── run_marker_preservation_analysis.py
    ├── run_biological_validation.py
    ├── analyze_c11_factor_biology.py
    ├── run_parameter_sensitivity.py
    └── run_sensitivity_followup.py
```

`legacy/pgnmf_revision/` is not a second PGNMF solver package. It contains
only the small set of experiment-time data, masking, graph, pathway, and
evaluation helpers still imported by the selected analysis scripts. All
model-fitting scripts use the maintained solver
`pgnmf.solver.zero_aware_nmf_mu_blocked` from `src/pgnmf/`.

## Installation

From the repository root:

```bash
python -m pip install -e .
python -m pip install -r reproducibility/requirements-experiments.txt
```

The core package itself requires Python 3.10 or later. The additional
requirements are needed for AnnData/Scanpy-based dataset workflows,
clustering, UMAP, and biological analyses.

## Main single-dataset run

Prepare the masked and reference AnnData files, the fixed mask plan, the
selected-gene mask, and a pathway GMT file. Then run the maintained exact
gene-block implementation:

```bash
python reproducibility/scripts/run_single_dataset_exact_block.py \
  --dataset C11 \
  --masked work/C11/masked_logcp10k.h5ad \
  --reference work/C11/reference_logcp10k.h5ad \
  --mask-plan work/C11/mask_plan.npz \
  --gene-set-masks audit/C11/stage2cpre_gene_set_diagnostic/gene_set_masks.npz \
  --gene-set-key "HVG1000+PATHWAY" \
  --gmt data/c2.cp.kegg_legacy.v2025.1.Hs.symbols.gmt \
  --label-key majority_voting \
  --resolution 0.4 \
  --output-dir results/C11_pgnmf
```

The example configuration `configs/c11_stage2c8_rank80.json` records the
C11 rank-80 Stage2C8 parameter setting. Confirm its dataset-specific Leiden
resolution against the final archived run record before treating it as a
frozen reproduction manifest. The block size is a computational setting,
not a model hyperparameter.

The generic runner is a reusable single-dataset entry point. It is not a
claim that every dataset-specific benchmark in the manuscript has already
been rerun from this public package.

## Selected manuscript analyses

The scripts are grouped by purpose rather than by their original internal
Stage2C identifiers:

| Script | Purpose |
|---|---|
| `prepare_masked_input.py` | Prepare a fixed simulated-missing evaluation input from an authorized AnnData dataset. |
| `evaluate_imputed.py` | Evaluate an imputed matrix on the fixed mask and clustering protocol. |
| `run_component_ablation.py` | Component-level ablation of the PGNMF objective. |
| `run_pathway_sparsity_ablation.py` | Pathway-prior and hierarchical-sparsity ablations. |
| `run_additional_c11_ablation.py` | Additional C11 ablations, including matched feature-set comparisons. |
| `run_convergence_analysis.py` | Convergence trace and associated diagnostics. |
| `run_parameter_sensitivity.py` | C11 parameter-sensitivity analysis. |
| `run_sensitivity_followup.py` | Follow-up convergence and initialization-stability analyses. |
| `run_marker_preservation_analysis.py` | Held-out marker preservation analysis and its associated outputs. |
| `run_biological_validation.py` | Marker-recovery/leakage and pathway-coexpression validation. |
| `analyze_c11_factor_biology.py` | Post-hoc factor/cell-type association and KEGG enrichment analysis. |
| `run_truek_secondary_benchmark.py` | Secondary True-K clustering benchmark. |

The analysis scripts may save figures as part of an analysis workflow, but
standalone plot-only scripts and temporary visualization experiments are
intentionally not included. The repository is focused on the algorithm and
the analyses needed to support the manuscript, not on publishing every
intermediate plotting file.

Run any script with `--help` to inspect its arguments. Do not run all scripts
in sequence: several analyses require outputs from earlier steps. In
particular:

- `run_biological_validation.py` uses the held-out factor cache generated by
  `run_marker_preservation_analysis.py`.
- `analyze_c11_factor_biology.py` uses the frozen C11 factor cache and
  corresponding gene-selection mask.
- `run_sensitivity_followup.py` loads and reuses
  `run_parameter_sensitivity.py`.

## Input data and external resources

The repository does not distribute raw or controlled-access scRNA-seq data,
prepared `.h5ad` files, masks, intermediate factor caches, benchmark outputs,
or the GMT pathway collection. Place local files in paths supplied on the
command line. The historical analysis scripts use the conventional local
folders `data/`, `work/`, `audit/`, and `results/` relative to the repository
root; these folders are intentionally excluded from version control.

The pathway GMT resource used in the manuscript is a third-party MSigDB
C2:CP:KEGG_LEGACY collection. Obtain the appropriate version from MSigDB and
follow its registration, citation, and license terms. The repository's MIT
License applies only to the PGNMF code, not to external datasets or pathway
resources.

## Reproducibility scope

The original local PowerShell batch scheduler, dataset-specific annotation
scripts, temporary diagnostics, standalone plot-only scripts, and historical
solver-development versions have been omitted from this compact release.
The retained scripts cover the principal model, ablation, convergence,
sensitivity, and biological-analysis workflows.

The source archive used to prepare this release did not include all original
per-dataset run manifests, local input matrices, masks, caches, and final
audit outputs. Consequently, the scripts have been syntax-checked and the
core package has been unit-tested, but the full manuscript analyses have not
been rerun end-to-end from this release. Exact reproduction of a particular
table or figure requires the matching input files, dataset-specific
configuration, and frozen settings used in the manuscript.
